Manual de Lince

Los 27 ejemplos de esta página no están escritos a mano: son archivos .lince del repositorio que se ejecutan al generar el manual, y lo que ves bajo cada uno es su salida real. Si el lenguaje cambia de comportamiento, la página deja de cuadrar y la integración continua lo detecta — así la documentación no puede quedarse mintiendo.

Nada coincide con esa búsqueda.

Primeros pasos

Hola, mundo

`escribir` imprime y añade un salto de línea.

010_hola.lince

Variables y constantes

`sea` crea algo que puede cambiar; `fijo`, algo que no.

sea nombre = "Ana"
fijo PI = 3.14159

nombre = "Blanca"
escribir(nombre)
escribir(PI)
salida verificada
Blanca
3.14159
020_variables.lince

Cada nombre se define una sola vez

Definir dos veces en el mismo ámbito es un error, no un descarte silencioso. Para cambiar el valor, asigna.

sea contador = 1
contador = 2
escribir(contador)

intentar {
    sea contador = 3
} capturar (error e) {
    escribir(e.mensaje)
}
salida verificada
2
030_una_vez.lince

Tapar un nombre en un ámbito interior

Esto no es redefinir: es otro ámbito. El de fuera queda intacto.

sea visible = "fuera"

funcion dentro(): texto {
    sea visible = "dentro"
    devolver visible
}

escribir(dentro())
escribir(visible)
salida verificada
dentro
fuera
040_tapar.lince

Dónde se declaran los tipos

En parámetros y retorno de función son obligatorios. En `sea` son opcionales y sólo para `lista` y `diccionario`.

sea lista notas = [9, 7, 10]
sea diccionario ficha = {"nombre": "Ana"}

funcion presentar(val texto quien, val numero anios): texto {
    devolver quien + " tiene " + anios + " años"
}

escribir(presentar(ficha["nombre"], notas.longitud()))
salida verificada
Ana tiene 3 años
050_tipos.lince

Control de flujo

Condicionales

`si`, `sino si`, `sino`. Los operadores lógicos son `y`, `o`, `no`.

sea nota = 7

si nota >= 9 {
    escribir("sobresaliente")
} sino si nota >= 5 {
    escribir("aprobado")
} sino {
    escribir("suspenso")
}

si nota > 5 y no (nota == 10) {
    escribir("entre 6 y 9")
}
salida verificada
aprobado
entre 6 y 9
110_condicionales.lince

Las cuatro formas de repetir

`para` clásico, `mientras`, `hacer/mientras` y `para cada`.

para (i = 0; i < 3; i++) {
    escribir("para " + i)
}

sea n = 0
mientras n < 2 {
    escribir("mientras " + n)
    n = n + 1
}

sea m = 0
hacer {
    escribir("hacer " + m)
    m = m + 1
} mientras (m < 2)

para cada numero x en [10, 20] {
    escribir("cada " + x)
}
salida verificada
para 0
para 1
para 2
mientras 0
mientras 1
hacer 0
hacer 1
cada 10
cada 20

Elegir / caso

`otro` es el caso por defecto.

sea animal = "lince"

elegir animal {
    caso "gato"  { escribir("miau") }
    caso "lince" { escribir("es un felino ibérico") }
    otro         { escribir("no sé qué hace") }
}
salida verificada
es un felino ibérico

escribir(area(10, 4))

Valores por defecto

Los parámetros con valor por defecto van al final.

funcion saludo(val texto nombre, val texto trato = "Hola"): texto {
    devolver trato + ", " + nombre
}

escribir(saludo("Ana"))
escribir(saludo("Ana", "Buenas"))

Hola, Ana
Buenas, Ana

Lambdas y funciones como argumento

Una función sin nombre es un valor como cualquier otro.

sea doble = funcion(val numero x): numero { devolver x * 2 }
escribir(doble(21))

sea nums = [1, 2, 3, 4]
escribir(mapear(nums, doble))
escribir(filtrar(nums, funcion(val numero x): logico { devolver x % 2 == 0 }))
escribir(reducir(nums, 0, funcion(val numero a, val numero x): numero { devolver a + x }))
salida verificada
42
[2, 4, 6, 8]
[2, 4]
10

Closures

Una función recuerda el ámbito donde se creó, así que puede llevar estado.

funcion contador_desde(val numero inicio): funcion {
    sea n = inicio
    devolver funcion(): numero {
        n = n + 1
        devolver n
    }
}

sea siguiente = contador_desde(10)
escribir(siguiente())
escribir(siguiente())
escribir(siguiente())
salida verificada
11
12
13

Listas

Crear, modificar y consultar

`agregar`, `eliminar` e `insertar` cambian la lista; `longitud`, `posicion` y `contiene` sólo la leen.

sea notas = [9, 7, 10]
notas.agregar(6)
escribir(notas)
escribir(notas.longitud())

escribir(notas.contiene(7))

Operaciones que devuelven una lista nueva

`ordenar`, `invertir` y `copiar` no tocan la original.

sea original = [3, 1, 2]
escribir(original.ordenar())
escribir(original.invertir())
escribir(original)

[1, 2, 3]

[3, 1, 2]

Ordenar con tu propio criterio

La función comparadora devuelve negativo, cero o positivo. La ordenación es estable.

sea nums = [3, 1, 4, 1, 5]

escribir(nums.ordenar())
escribir(nums.ordenar(funcion(val numero a, val numero b): numero {
    devolver b - a
}))
salida verificada
[1, 1, 3, 4, 5]
[5, 4, 3, 1, 1]

Diccionarios

Crear, leer y recorrer

Las claves son texto. `para cada` sobre un diccionario recorre las claves.

sea persona = {"nombre": "Ana", "edad": 22}
persona["ciudad"] = "Córdoba"

escribir(persona["nombre"])
escribir(persona.longitud())

para cada texto clave en persona {
    escribir(clave + " = " + persona[clave])
}
salida verificada
Ana
3
nombre = Ana
edad = 22
ciudad = Córdoba

Métodos de texto

Clases

Clase, constructor y métodos

`mi` es la instancia actual. El constructor se llama `crear`.

clase Rectangulo {
    funcion crear(val numero ancho, val numero alto): nulo {
        mi.ancho = ancho
        mi.alto  = alto
    }
    funcion area(): numero {
        devolver mi.ancho * mi.alto
    }
}

sea r = Rectangulo(4, 3)
escribir(r.area())
salida verificada
12
610_clases.lince

Herencia

`extiende` hereda; `padre(...)` llama al constructor de arriba.

clase Figura {
    funcion crear(val texto nombre): nulo { mi.nombre = nombre }
    funcion describir(): texto { devolver "soy un " + mi.nombre }
}

clase Cuadrado extiende Figura {
    funcion crear(val numero lado): nulo {
        padre("cuadrado")
        mi.lado = lado
    }
    funcion area(): numero { devolver mi.lado * mi.lado }
}

sea c = Cuadrado(5)
escribir(c.describir())
escribir(c.area())
salida verificada
soy un cuadrado
25

Generadores

Producir valores de uno en uno

`generador` en vez de `funcion`, y `producir` en vez de `devolver`.

generador pares(val numero hasta): numero {
    para (i = 0; i <= hasta; i++) {
        si i % 2 == 0 { producir i }
    }
}

para cada numero p en pares(8) {
    escribir(p)
}
salida verificada
0
2
4
6
8

Errores

Intentar, capturar, finalmente

`capturar (error e)` atrapa cualquier tipo; con un tipo concreto, sólo ese.

intentar {
    sea lista nums = [1, 2, 3]
    escribir(nums[99])
} capturar (ErrorRango e) {
    escribir("fuera de rango: " + e.mensaje)
} capturar (error e) {
    escribir("otro error")
} finalmente {
    escribir("esto se ejecuta siempre")
}
salida verificada
fuera de rango: Índice 99 fuera de rango. La lista tiene 3 elementos.
esto se ejecuta siempre
810_errores.lince

Lanzar errores propios

Tipos predefinidos: Error, ErrorTipo, ErrorRango, ErrorNulo, ErrorMatematico, ErrorArgumento.

funcion raiz_entera(val numero n): numero {
    si n < 0 {
        lanzar ErrorArgumento("no hay raíz real de un número negativo")
    }
    devolver n
}

intentar {
    escribir(raiz_entera(-1))
} capturar (ErrorArgumento e) {
    escribir("[" + e.tipo + "] " + e.mensaje)
}
salida verificada
[ErrorArgumento] no hay raíz real de un número negativo
820_lanzar.lince

El primer error es el que cuenta

Un error no se tapa con sus propias consecuencias: se informa de la causa, no del fallo que vino detrás.

intentar {
    escribir(noExiste())
} capturar (error e) {
    escribir("[" + e.tipo + "] " + e.mensaje)
}

intentar {
    sea cinco = 5
    escribir(cinco(1))
} capturar (ErrorTipo e) {
    escribir("[" + e.tipo + "] " + e.mensaje)
}
salida verificada
[Error] La variable 'noExiste' no está definida.
[ErrorTipo] 'cinco' no es una función, así que no se puede llamar.
830_primer_error.lince

Los fallos de uso también se pueden capturar

Un método con los argumentos mal, un índice fuera de rango, un campo que no existe… llegan como errores con su tipo y se pueden capturar. Sin capturar, el mensaje dice la línea.

sea lista notas = [9, 7]

intentar {
    notas.agregar()
} capturar (ErrorArgumento e) {
    escribir("[" + e.tipo + "] " + e.mensaje)
}

intentar {
    notas[5] = 1
} capturar (ErrorRango e) {
    escribir("[" + e.tipo + "] " + e.mensaje)
}

clase Caja {
    funcion crear(val numero v): nulo { mi.v = v }
}

intentar {
    sea c = Caja(1)
    escribir(c.contenido)
} capturar (error e) {
    escribir("[" + e.tipo + "] " + e.mensaje)
}
salida verificada
[ErrorArgumento] 'agregar' necesita exactamente 1 argumento.
[ErrorRango] Índice 5 fuera de rango. La lista tiene 2 elementos.
[Error] El objeto no tiene el campo 'contenido'.

Importar un archivo tuyo

La ruta se resuelve junto al archivo que importa, no desde donde lanzas el programa. Importar dos veces el mismo archivo no hace nada la segunda.

importar "./lib_geometria"

escribir(area_circulo(1.0))
salida verificada
3.14159

Con espacio de nombres: `como`

Con `como`, el archivo corre en su propio ámbito y sólo se alcanza por el alias. Así dos librerías pueden tener funciones del mismo nombre.

importar "./lib_metros" como metros
importar "./lib_pies"   como pies

escribir(metros.convertir(100))
escribir(pies.convertir(100))
escribir(metros.UNIDAD)
salida verificada
100
