Variables con tipo

Delante del nombre puede ir su tipo, como en los parámetros (numero, texto, logico, lista, funcion, una clase...). No es obligatorio; si se pone, el valor inicial tiene que ser de ese tipo, y lince comprobar y el editor avisan si más adelante se le da otro.

sea numero vida = 3
sea texto nombre = "Ana"
fijo logico MODO_FACIL = verdadero

intentar {
    sea numero puntos = "cero"
} capturar (ErrorTipo e) {
    escribir(e.mensaje)
}
escribir("{nombre}: {vida} vidas, fácil: {MODO_FACIL}")
salida verificada
Error de tipo en variable 'puntos': se esperaba 'numero' pero se recibió 'texto'.
Ana: 3 vidas, fácil: verdadero
022_con_tipo.lince

Operar y guardar: +=, -=, ++, --

x += 5 es x = x + 5 (también -=, *=, /= y %=), y x++ suma uno (x-- resta uno). Valen para variables, elementos de listas y diccionarios, y campos (mi.vidas--).

sea puntos = 10
puntos += 5
puntos *= 2
escribir(puntos)

sea nombre = "Lin"
nombre += "ce"
escribir(nombre)

sea vidas = {"Ana": 3, "Luis": 3}
vidas["Luis"] -= 1
escribir(vidas)

sea marcador = [3, 3]
marcador[1]--
marcador[0]++
escribir(marcador)
salida verificada
30
Lince

[4, 2]

Condicionales

si, sino si, sino. Los operadores lógicos son y, o, no.

sea nota = 7

si nota >= 9 {
    escribir("sobresaliente")
} sino si nota >= 5 {
    escribir("aprobado")
} sino {
    escribir("suspenso")
}

si nota > 5 y no (nota == 10) {
    escribir("entre 6 y 9")
}

        romper

para (i = 0; i < 20; i += 5) {

val y ref

Delante de un parámetro se puede poner val (lo normal; da igual ponerlo o no) o ref. Con ref, lo que valga el parámetro al acabar la función pasa a la variable que se le dio. Las listas y los diccionarios se comparten siempre: si la función les añade algo, se ve fuera.

funcion intercambiar(ref numero a, ref numero b): nulo {
    sea t = a
    a = b
    b = t
}
funcion apuntar(lista marcas, numero tiempo): nulo {
    marcas.agregar(tiempo)
}
sea x = 1
sea y = 2
intercambiar(x, y)
escribir("x = {x}, y = {y}")
sea marcas = []
apuntar(marcas, 12.5)
escribir(marcas)
salida verificada
x = 2, y = 1
[12.5]

Llamar a cualquier cosa que dé una función

Una función es un valor más: se guarda en una lista, en un diccionario o en un campo, y se llama directamente desde ahí. También se puede llamar a lo que devuelve otra llamada. El ( va en la misma línea que lo que se llama.

sea golpes = [
    funcion(numero f): texto { devolver "puñetazo de " + f },

escribir(golpes[1](8))

sea acciones = {"saltar": funcion(): texto { devolver "¡hop!" }}
escribir(acciones["saltar"]())

funcion sumador(numero a): funcion {
    devolver funcion(numero b): numero { devolver a + b }
}
escribir(sumador(2)(3))

Interfaces

Una interfaz lista los métodos que una clase promete tener. Si a la clase le falta alguno, implementa da error al declararla.

interfaz Forma {
    funcion area(): numero
    funcion describir(): texto
}

clase Rectangulo implementa Forma {
    funcion crear(numero ancho, numero alto): nulo {
        mi.ancho = ancho
        mi.alto = alto
    }
    funcion area(): numero {
        devolver mi.ancho * mi.alto
    }
    funcion describir(): texto {
        devolver "Rectángulo " + mi.ancho + "x" + mi.alto
    }
}

clase Cuadrado implementa Forma {
    funcion crear(numero lado): nulo {
        mi.lado = lado
    }
    funcion area(): numero {
        devolver mi.lado * mi.lado
    }
    funcion describir(): texto {
        devolver "Cuadrado de lado " + mi.lado
    }
}

sea lista formas = [Rectangulo(2, 3), Cuadrado(5)]
para cada Forma f en formas {
    escribir(f.describir() + " → " + f.area())

Enumeraciones

Una enumeracion da nombre a un conjunto fijo de valores: los estados de un personaje, las direcciones... Se comparan con ==, encajan en elegir y se recorren con para cada. Cada uno tiene nombre, indice (su posición) y valor: el que se le dé con =, o su posición. Si a un elegir sin otro le faltan valores, Lince avisa al empezar.

enumeracion Estado { Quieto Andando Saltando }

enumeracion Direccion {
    Arriba = [0, -1]
    Abajo = [0, 1]
    Izquierda = [-1, 0]
    Derecha = [1, 0]
}

funcion animacion(Estado e): texto {
    elegir e {
        caso Estado.Quieto { devolver "respirar" }
        caso Estado.Andando { devolver "andar" }
        caso Estado.Saltando { devolver "saltar" }
    }
    devolver ""
}

sea estado = Estado.Andando
escribir(estado)
escribir(animacion(estado))
escribir(estado == Estado.Andando)

para cada Direccion d en Direccion {
    escribir(d.nombre + " mueve " + d.valor)
}
escribir(Direccion.Izquierda.indice)
salida verificada
Estado.Andando
andar

Visibilidad: `privado` y `protegido`

Lo privado sólo se ve desde dentro de la clase; lo protegido, también desde sus subclases. Saltárselo lanza un ErrorAcceso, que se captura como cualquier error.

clase Cuenta {
    privado sea saldo = 0

    funcion ingresar(numero cantidad): nulo {
        mi.saldo = mi.saldo + cantidad
    }
    funcion consultar(): numero {
        devolver mi.saldo
    }
}

sea c = Cuenta()
c.ingresar(50)
escribir(c.consultar())

intentar {
    escribir(c.saldo)
} capturar (ErrorAcceso e) {
    escribir("No se puede: " + e.mensaje)
}
salida verificada
50
No se puede: El campo 'saldo' de 'Cuenta' es privado: no se puede leer desde aquí.

Miembros estáticos

estatico hace que un campo o método pertenezca a la clase y no a cada objeto. Se usan con el nombre de la clase. Un método estático no tiene mi.

clase Pedido {
    estatico sea creados = 0
    estatico fijo IVA = 21

    funcion crear(numero base): nulo {
        mi.base = base
        Pedido.creados = Pedido.creados + 1
    }
    estatico funcion con_iva(numero base): numero {

Probar cosas sueltas: el REPL

Paquetes y editores

lince instalar descarga una librería de Lince (un repositorio git) para usarla con importar "paquete:nombre". Con una versión (@v1.2: una etiqueta, una rama o un commit) el paquete es del juego: va a su carpeta paquetes/ y se apunta en lince.paquetes con su huella; lince instalar sin nada más baja exactamente esos en otro ordenador, y no instala uno que haya cambiado desde entonces. Para el editor hay una extensión de VS Code con colores, plantillas, errores y avisos al escribir, autocompletado, ir a la definición, la ayuda al pasar el ratón y formatear al guardar; por debajo usa lince lsp, que cualquier editor que hable LSP puede usar.

lince instalar https://github.com/usuario/paquete
lince instalar https://github.com/usuario/paquete@v1.2   # para este juego, esa versión
lince instalar                                          # los de lince.paquetes
lince listar
lince desinstalar paquete
code --install-extension lince-language-X.Y.Z.vsix   # viene con cada versión
