Los 54 ejemplos de esta página no están escritos a mano: son archivos .lince del repositorio que se ejecutan al generar el manual, y lo que ves bajo cada uno es su salida real. 020_variables.lince

Operar y guardar: +=, -=, ++, --

x += 5 es x = x + 5 (también -=, *=, /= y %=), y x++ suma uno (x-- resta uno). Valen para variables, elementos de listas y diccionarios, y campos (mi.vidas--).

sea puntos = 10
puntos += 5
puntos *= 2
escribir(puntos)

sea nombre = "Lin"
nombre += "ce"
escribir(nombre)

sea vidas = {"Ana": 3, "Luis": 3}
vidas["Luis"] -= 1
escribir(vidas)

sea marcador = [3, 3]
marcador[1]--
marcador[0]++
escribir(marcador)
salida verificada
30
Lince

Llamar a cualquier cosa que dé una función

Una función es un valor más: se guarda en una lista, en un diccionario o en un campo, y se llama directamente desde ahí. También se puede llamar a lo que devuelve otra llamada. El ( va en la misma línea que lo que se llama.

escribir(golpes[1](8))

sea acciones = {"saltar": funcion(): texto { devolver "¡hop!" }}
escribir(acciones["saltar"]())

funcion sumador(val numero a): funcion {
    devolver funcion(val numero b): numero { devolver a + b }
}
escribir(sumador(2)(3))

    funcion area(): numero {
        devolver mi.ancho * mi.alto

Enumeraciones

Una enumeracion da nombre a un conjunto fijo de valores: los estados de un personaje, las direcciones... Se comparan con ==, encajan en elegir y se recorren con para cada. Cada uno tiene nombre, indice (su posición) y valor: el que se le dé con =, o su posición. Si a un elegir sin otro le faltan valores, Lince avisa al empezar.

enumeracion Estado { Quieto Andando Saltando }

enumeracion Direccion {
    Arriba = [0, -1]
    Abajo = [0, 1]
    Izquierda = [-1, 0]
    Derecha = [1, 0]
}

funcion animacion(val Estado e): texto {
    elegir e {
        caso Estado.Quieto   { devolver "respirar" }
        caso Estado.Andando  { devolver "andar" }
        caso Estado.Saltando { devolver "saltar" }
    }
    devolver ""
}

sea estado = Estado.Andando
escribir(estado)
escribir(animacion(estado))
escribir(estado == Estado.Andando)

para cada Direccion d en Direccion {
    escribir(d.nombre + " mueve " + d.valor)
}
escribir(Direccion.Izquierda.indice)
salida verificada
Estado.Andando
andar
verdadero

Abajo mueve [0, 1]
Izquierda mueve [-1, 0]
Derecha mueve [1, 0]

Visibilidad: `privado` y `protegido`

Lo privado sólo se ve desde dentro de la clase; lo protegido, también desde sus subclases. Saltárselo lanza un ErrorAcceso, que se captura como cualquier error.

clase Cuenta {
    privado sea saldo = 0

    funcion ingresar(val numero cantidad): nulo {
        mi.saldo = mi.saldo + cantidad
    }
    funcion consultar(): numero {
        devolver mi.saldo
    }
}

sea c = Cuenta()
c.ingresar(50)
escribir(c.consultar())

intentar {
    escribir(c.saldo)
} capturar (ErrorAcceso e) {
    escribir("No se puede: " + e.mensaje)
}
salida verificada
50
No se puede: El campo 'saldo' de 'Cuenta' es privado: no se puede leer desde aquí.

Clases abstractas y `sobrescribe`

Una clase abstracta no se instancia y puede exigir métodos abstracto a sus subclases. sobrescribe avisa si el padre no tiene ese método, en vez de crear uno nuevo por una errata.

abstracta clase Figura {
    abstracto funcion area(): numero

    funcion describir(): texto {
        devolver "área " + mi.area()
    }
}

clase Cuadrado extiende Figura {
    funcion crear(val numero lado): nulo {
        mi.lado = lado
    }
    sobrescribe funcion area(): numero {
        devolver mi.lado * mi.lado
    }
}

escribir(Cuadrado(3).describir())

intentar {
    Figura()
} capturar (ErrorTipo e) {
    escribir(e.mensaje)
}
salida verificada
área 9
'Figura' es una clase abstracta y no se puede instanciar.
670_abstractas.lince

Propiedades, operadores y `a_texto`

obtener y fijar se usan como un campo pero ejecutan código, así que pueden validar. Los métodos sumar, igual, menor... dan sentido a los operadores, y a_texto decide cómo se escribe el objeto.

clase Vector {
    privado sea _x = 0
    obtener x(): numero { devolver mi._x }
    fijar x(val numero v): nulo {
        si v < 0 { lanzar Error("x no puede ser negativa") }
        mi._x = v
    }
    funcion sumar(val Vector b): Vector {
        sea r = Vector()
        r.x = mi.x + b.x
        devolver r
    }
    funcion menor(val Vector b): logico { devolver mi.x < b.x }
    funcion igual(val Vector b): logico { devolver mi.x == b.x }
    funcion a_texto(): texto { devolver "Vector(" + mi.x + ")" }
}

sea a = Vector()
a.x = 2
sea b = Vector()
b.x = 5
escribir(a + b)
escribir(a < b)
escribir(a == b)

intentar {
    a.x = -1
} capturar (Error e) {
    escribir(e.mensaje)
}
salida verificada
Vector(7)
verdadero
falso
x no puede ser negativa

710_generadores.lince

Uno que no acaba nunca

Cada valor se calcula cuando para cada lo pide, así que un generador puede no acabar: se sale con romper o devolver, y entonces se para (con su finalmente). Un generador se recorre una vez.

generador naturales(): numero {
    sea n = 1
    mientras verdadero {
        producir n
        n++
    }
}

para cada numero n en naturales() {
    si n * n > 50 {
        escribir("el primero con el cuadrado mayor que 50 es " + n)
        romper
    }
}
salida verificada
el primero con el cuadrado mayor que 50 es 8
715_generador_sin_fin.lince

Un generador guardado sigue por donde iba

Guardado en una variable, un generador recuerda dónde se quedó: el siguiente para cada continúa tras el romper. Los valores se calculan cuando se piden, así que rango() sirve aunque sea enorme.

generador turnos(): texto {
    mientras verdadero {
        producir "Ana"
        producir "Luis"
        producir "Marta"
    }
}

Esperar sin parar el juego

Una tarea se escribe como una función y empieza a correr al llamarla. esperar() la deja aparcada en esa línea hasta el fotograma siguiente; esperar(segundos), hasta que pase ese tiempo, y esperar(otra), hasta que otra tarea acabe (y da lo que devolvió). Mientras, todo lo demás sigue. En un juego avanzan solas en cada juego.presentar(); aquí, sin juego, avanzan mientras el programa espera.

tarea parpadear(val texto quien, val numero veces) {
    para (i = 0; i < veces; i++) {
        escribir(quien + ": brilla")
        esperar()

    escribir(quien + ": desaparece")
}

tarea jefe(): texto {
    escribir("jefe: carga el golpe")
    esperar(0.2)
    escribir("jefe: ¡golpe!")
    devolver "fin del ataque"
}

parpadear("moneda", 2)
parpadear("estrella", 3)
escribir(esperar(jefe()))

sea t = parpadear("vela", 100)
esperar()

Ejecutar, comprobar y compilar

lince nuevo mi_juego                    # una carpeta con un juego para empezar
lince version
