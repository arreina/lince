Manual de Lince

Los 43 ejemplos de esta página no están escritos a mano: son archivos .lince del repositorio que se ejecutan al generar el manual, y lo que ves bajo cada uno es su salida real. Si el lenguaje cambia de comportamiento, la página deja de cuadrar y la integración continua lo detecta — así la documentación no puede quedarse mintiendo.

Nada coincide con esa búsqueda.

Condicionales

`si`, `sino si`, `sino`. Los operadores lógicos son `y`, `o`, `no`.

sea nota = 7

si nota >= 9 {
    escribir("sobresaliente")
} sino si nota >= 5 {
    escribir("aprobado")
} sino {
    escribir("suspenso")
}

si nota > 5 y no (nota == 10) {
    escribir("entre 6 y 9")
}

Las cuatro formas de repetir

`para` clásico, `mientras`, `hacer/mientras` y `para cada`.

para (i = 0; i < 3; i++) {
    escribir("para " + i)
}

sea n = 0
mientras n < 2 {
    escribir("mientras " + n)
    n = n + 1
}

sea m = 0
hacer {
    escribir("hacer " + m)
    m = m + 1
} mientras (m < 2)

para cada numero x en [10, 20] {
    escribir("cada " + x)
}

Interfaces

Una `interfaz` lista los métodos que una clase promete tener. Si a la clase le falta alguno, `implementa` da error al declararla.

interfaz Forma {
    funcion area(): numero
    funcion describir(): texto
}

clase Rectangulo implementa Forma {
    funcion crear(val numero ancho, val numero alto): nulo {
        mi.ancho = ancho
        mi.alto  = alto
    }
    funcion area(): numero {
        devolver mi.ancho * mi.alto
    }
    funcion describir(): texto {
        devolver "Rectángulo " + mi.ancho + "x" + mi.alto
    }
}

clase Cuadrado implementa Forma {
    funcion crear(val numero lado): nulo {
        mi.lado = lado
    }
    funcion area(): numero {
        devolver mi.lado * mi.lado
    }
    funcion describir(): texto {
        devolver "Cuadrado de lado " + mi.lado
    }
}

sea lista formas = [Rectangulo(2, 3), Cuadrado(5)]
para cada elemento f en formas {
    escribir(f.describir() + " → " + f.area())
}
salida verificada
Rectángulo 2x3 → 6
Cuadrado de lado 5 → 25

Enumeraciones

Una `enumeracion` da nombre a un conjunto fijo de valores. Se comparan con `==` y encajan en `elegir`.

enumeracion Semaforo {
    Rojo
    Ambar
    Verde
}

funcion accion(val texto s): texto {
    elegir s {
        caso Semaforo.Rojo  { devolver "parar" }
        caso Semaforo.Ambar { devolver "precaución" }
        otro                { devolver "avanzar" }
    }
    devolver ""
}

sea luz = Semaforo.Ambar
escribir(luz == Semaforo.Ambar)
escribir(accion(Semaforo.Rojo))
escribir(accion(luz))
escribir(accion(Semaforo.Verde))

Visibilidad: `privado` y `protegido`

Lo `privado` sólo se ve desde dentro de la clase; lo `protegido`, también desde sus subclases. Saltárselo lanza un `ErrorAcceso`, que se captura como cualquier error.

clase Cuenta {
    privado sea saldo = 0

    funcion ingresar(val numero cantidad): nulo {
        mi.saldo = mi.saldo + cantidad
    }
    funcion consultar(): numero {
        devolver mi.saldo
    }
}

sea c = Cuenta()
c.ingresar(50)
escribir(c.consultar())

intentar {
    escribir(c.saldo)
} capturar (ErrorAcceso e) {
    escribir("No se puede: " + e.mensaje)
}
salida verificada
50
No se puede: El campo 'saldo' de 'Cuenta' es privado: no se puede leer desde aquí.

Miembros estáticos

`estatico` hace que un campo o método pertenezca a la clase y no a cada objeto. Se usan con el nombre de la clase. Un método estático no tiene `mi`.

    estatico fijo IVA = 21

    funcion crear(val numero base): nulo {
        mi.base = base
        Pedido.creados = Pedido.creados + 1
    }
    estatico funcion con_iva(val numero base): numero {
        devolver base + base * Pedido.IVA / 100
    }
}

Pedido(10)
Pedido(20)
escribir(Pedido.creados)
escribir(Pedido.con_iva(100))

Clases abstractas y `sobrescribe`

Una clase `abstracta` no se instancia y puede exigir métodos `abstracto` a sus subclases. `sobrescribe` avisa si el padre no tiene ese método, en vez de crear uno nuevo por una errata.

abstracta clase Figura {
    abstracto funcion area(): numero

    funcion describir(): texto {
        devolver "área " + mi.area()
    }
}

clase Cuadrado extiende Figura {
    funcion crear(val numero lado): nulo {
        mi.lado = lado
    }
    sobrescribe funcion area(): numero {
        devolver mi.lado * mi.lado
    }
}

escribir(Cuadrado(3).describir())

intentar {
    Figura()
} capturar (ErrorTipo e) {
    escribir(e.mensaje)
}
salida verificada
área 9
'Figura' es una clase abstracta y no se puede instanciar.
670_abstractas.lince

Propiedades, operadores y `a_texto`

`obtener` y `fijar` se usan como un campo pero ejecutan código, así que pueden validar. Los métodos `sumar`, `igual`, `menor`... dan sentido a los operadores, y `a_texto` decide cómo se escribe el objeto.

clase Vector {
    privado sea _x = 0
    obtener x(): numero { devolver mi._x }
    fijar x(val numero v): nulo {
        si v < 0 { lanzar Error("x no puede ser negativa") }
        mi._x = v
    }
    funcion sumar(val Vector b): Vector {
        sea r = Vector()
        r.x = mi.x + b.x
        devolver r
    }
    funcion menor(val Vector b): logico { devolver mi.x < b.x }
    funcion igual(val Vector b): logico { devolver mi.x == b.x }
    funcion a_texto(): texto { devolver "Vector(" + mi.x + ")" }
}

sea a = Vector()
a.x = 2
sea b = Vector()
b.x = 5
escribir(a + b)
escribir(a < b)
escribir(a == b)

intentar {
    a.x = -1
} capturar (Error e) {
    escribir(e.mensaje)
}
salida verificada
Vector(7)
verdadero
falso
x no puede ser negativa

Métodos por defecto y el operador `es`

Una interfaz puede dar el cuerpo de un método: las clases que la implementan lo reciben sin repetirlo. `x es Tipo` comprueba la clase, la interfaz o el tipo básico de un valor.

interfaz Saludable {
    funcion nombre(): texto
    funcion saludar(): texto {
        devolver "Hola, soy " + mi.nombre()
    }
}

clase Persona implementa Saludable {
    funcion nombre(): texto { devolver "Ana" }
}
clase Robot { }

sea p = Persona()
escribir(p.saludar())
escribir(p es Saludable)
escribir(Robot() es Saludable)
escribir(p es Persona)
escribir(5 es numero)
salida verificada
Hola, soy Ana
verdadero
falso
verdadero
verdadero

El primer error es el que cuenta

Un error no se tapa con sus propias consecuencias: se informa de la causa, no del fallo que vino detrás.

intentar {
    escribir(noExiste())
} capturar (error e) {
    escribir("[" + e.tipo + "] " + e.mensaje)
}

intentar {
    sea cinco = 5
    escribir(cinco(1))
} capturar (ErrorTipo e) {
    escribir("[" + e.tipo + "] " + e.mensaje)
}
salida verificada
[Error] La variable 'noExiste' no está definida.
[ErrorTipo] 'cinco' no es una función, así que no se puede llamar.
830_primer_error.lince

Los fallos de uso también se pueden capturar

Un método con los argumentos mal, un índice fuera de rango, un campo que no existe… llegan como errores con su tipo y se pueden capturar. Sin capturar, el mensaje dice la línea.

sea lista notas = [9, 7]

intentar {
    notas.agregar()
} capturar (ErrorArgumento e) {
    escribir("[" + e.tipo + "] " + e.mensaje)
}

intentar {
    notas[5] = 1
} capturar (ErrorRango e) {
    escribir("[" + e.tipo + "] " + e.mensaje)
}

clase Caja {
    funcion crear(val numero v): nulo { mi.v = v }
}

intentar {
    sea c = Caja(1)
    escribir(c.contenido)
} capturar (error e) {
    escribir("[" + e.tipo + "] " + e.mensaje)
}
salida verificada
[ErrorArgumento] 'agregar' necesita exactamente 1 argumento.
[ErrorRango] Índice 5 fuera de rango. La lista tiene 2 elementos.
[Error] El objeto no tiene el campo 'contenido'.

El módulo `pruebas`

Pruebas unitarias para tus programas: `afirmar` comprueba una condición, `igual` compara valores (también listas y diccionarios), `lanza` comprueba que una función da error y `resumen` imprime el total y termina con código 1 si algo falló, ideal para la integración continua.

importar "pruebas"

funcion doble(val numero n): numero {
    devolver n * 2
}

pruebas.suite("doble")
pruebas.afirmar("doble de 4 es 8", doble(4) == 8)
pruebas.igual("una lista de dobles", [doble(1), doble(2)], [2, 4])
pruebas.lanza("dividir por cero da error", funcion(): nulo { sea x = 1 / 0 })
pruebas.resumen()

Fechas con `tiempo`

Una fecha es una marca de tiempo: segundos desde 1970, como `tiempo.ahora()`. `crear`, `formatear`, `partes` y `analizar` trabajan en hora local; sus versiones `_utc` no dependen de la zona horaria. `analizar` devuelve `nulo` si el texto no encaja con el formato.

importar "tiempo"

sea t = tiempo.crear_utc(2024, 2, 29, 13, 5, 9)
escribir(tiempo.formatear_utc(t, "%d/%m/%Y %H:%M"))
escribir(tiempo.formatear_utc(t + 86400, "%Y-%m-%d"))

sea p = tiempo.partes_utc(t)
escribir(p["anio"])
escribir(p["dia_anio"])

escribir(tiempo.analizar_utc("2024-02-29 13:05:09", "%Y-%m-%d %H:%M:%S") == t)
escribir(tiempo.analizar_utc("no es una fecha", "%Y-%m-%d"))

Bases de datos con `sqlite`

Necesita la biblioteca `libsqlite3` instalada en el sistema (Lince la carga al importar el módulo; si falta, da un `ErrorBD` claro). La conexión es un número; `consultar` devuelve una lista de diccionarios y los `?` se rellenan con la lista de parámetros, sin riesgo de inyección SQL. `":memoria:"` crea una base temporal.

importar "sqlite"

sea bd = sqlite.abrir(":memoria:")
sqlite.ejecutar(bd, "CREATE TABLE personas (id INTEGER PRIMARY KEY, nombre TEXT, edad INTEGER)")
sqlite.ejecutar(bd, "INSERT INTO personas (nombre, edad) VALUES (?, ?)", ["Ana", 31])
sqlite.ejecutar(bd, "INSERT INTO personas (nombre, edad) VALUES (?, ?)", ["Luis", 25])
escribir(sqlite.ultimo_id(bd))

para cada diccionario fila en sqlite.consultar(bd, "SELECT nombre, edad FROM personas WHERE edad > ? ORDER BY edad", [20]) {
    escribir(fila["nombre"] + " tiene " + fila["edad"])
}

intentar {
    sqlite.consultar(bd, "SELECT * FROM no_existe")
} capturar (ErrorBD e) {
    escribir("error: " + e.mensaje)
}
sqlite.cerrar(bd)

Hashes y base64 con `cripto`

`sha256`, `sha1` y `md5` devuelven el resumen en hexadecimal; `hmac_sha256(clave, texto)` firma un mensaje. `base64` y `hex` codifican, y `desbase64` y `deshex` deshacen el cambio (devuelven `nulo` si el texto no es válido). Para contraseñas no uses estos hashes sueltos: son rápidos de adivinar.

importar "cripto"

escribir(cripto.sha256("abc"))
escribir(cripto.md5("abc"))
escribir(cripto.hmac_sha256("clave", "mensaje"))

sea codificado = cripto.base64("Hola, Lince")
escribir(codificado)
escribir(cripto.desbase64(codificado))
escribir(cripto.hex("Lince"))
escribir(cripto.desbase64("esto no es base64"))
