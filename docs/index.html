El lenguaje

Todo lo que necesitas, en español

Clases, herencia, interfaces, generadores, closures, manejo de errores y módulos estándar. Sin rodeos.

hola.lince 
# Variables y tipos
sea  nombre = "Ana"
fijo PI     = 3.14159
sea lista notas = [9, 7, 10]

# Función con valor por defecto
funcion saludar(val texto nombre, val texto saludo = "Hola"): texto {
    devolver saludo + ", " + nombre
}

escribir(saludar("Mundo"))           # Hola, Mundo
escribir(saludar("Lince", "Bienvenido")) # Bienvenido, Lince

# Bucles
para cada numero n en rango(5) {
    escribir(n)
}

# Closures
funcion multiplicador(val numero factor): funcion {
    devolver funcion(val numero x): numero { devolver x * factor }
}
sea doble = multiplicador(2)
escribir(doble(5))   # 10
formas.lince 
interfaz Forma {
    funcion area(): numero
    funcion describir(): texto
}

clase Rectangulo implementa Forma {
    funcion crear(val numero ancho, val numero alto): nulo {
        mi.ancho = ancho
        mi.alto  = alto
    }
    funcion area(): numero  { devolver mi.ancho * mi.alto }
    funcion describir(): texto {
        devolver "Rectángulo " + mi.ancho + "x" + mi.alto
    }
}

clase Cuadrado extiende Rectangulo {
    funcion crear(val numero lado): nulo {
        padre(lado, lado)   # llama al constructor del padre
    }
}

sea c = Cuadrado(5)
escribir(c.area())        # 25
escribir(c.describir())   # Rectángulo 5x5
generadores.lince 
# Generadores — secuencias perezosas
generador pares(val numero hasta): numero {
    para cada numero n en rango(hasta) {
        si n % 2 == 0 { producir n }
    }
}

para cada numero n en pares(10) {
    escribir(n)   # 0, 2, 4, 6, 8
}

# Fibonacci infinito (evaluación perezosa)
generador fibonacci(): numero {
    sea a = 0
    sea b = 1
    mientras verdadero {
        producir a
        sea tmp = a + b
        a = b
        b = tmp
    }
}

sea gen = fibonacci()
para cada numero _ en rango(8) {
    escribir(gen.siguiente())   # 0 1 1 2 3 5 8 13
}
errores.lince 
# Manejo de errores estructurado
intentar {
    sea datos = json.parsear(archivos.leer("config.json"))
    escribir(datos["version"])
} capturar (ErrorRango e) {
    escribir("Clave no encontrada: " + e.mensaje)
} capturar (ErrorIO e) {
    escribir("No se pudo leer el archivo: " + e.mensaje)
} capturar (error e) {
    escribir("Error inesperado: " + e.mensaje)
} finalmente {
    escribir("Fin del proceso")
}

Por qué Lince

Diseñado para ser directo

Sin magia, sin frameworks gigantes, sin configuraciones misteriosas.

🇪🇸

100% en español

Palabras clave, mensajes de error y documentación en español. Programar no debería requerir saber inglés.

⚡

Compilador a binario nativo

Transpila a C y usa gcc -O2. El binario resultante es ~6.7x más rápido que el intérprete. Sin JVM, sin runtime.

📦

Sin dependencias

Un solo binario compilado con gcc y make. Funciona en Linux, Mac y Windows (MSYS2). Nada más que instalar.

🔍

Errores claros

Mensajes en español con número de línea exacto. Sin stack traces crípticos. El error dice exactamente qué falló.

🧩

Módulos incluidos

Matemáticas, texto, archivos, JSON, HTTP, expresiones regulares, tiempo y sistema. Listo para usar, sin pip ni npm.

📦

Librerías en Lince

Reparte tu código en archivos y dale un espacio de nombres con importar "./x" como x. Las rutas se resuelven junto al archivo que importa, así que una librería funciona desde cualquier sitio.

🔁

REPL interactivo

Ejecuta lince sin argumentos para entrar al REPL con historial persistente. Ideal para explorar y probar.

Rendimiento

Usa el intérprete para desarrollo rápido. Compila a binario cuando necesitas velocidad. El compilador es parte del mismo binario — sin herramientas extra.

Instalación

Empieza en dos comandos

Solo necesitas gcc y make. Sin gestores de paquetes, sin dependencias.

🐧 Linux / 🍎 Mac
$ git clone https://github.com/arreina/lince.git
$ cd lince && make
$ ./lince hola.lince

# Opcional: instalar globalmente
$ sudo make install
🪟 Windows (MSYS2/MinGW)
$ pacman -S mingw-w64-x86_64-gcc make
$ git clone https://github.com/arreina/lince.git
$ cd lince && make
$ ./lince hola.lince
