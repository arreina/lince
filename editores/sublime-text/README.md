# 🐆 Lince — Resaltado de sintaxis para Sublime Text

## Instalación

1. Abre Sublime Text
2. Ve a **Preferences → Browse Packages...**
3. Crea una carpeta llamada `Lince`
4. Copia dentro los archivos:
   - `lince.tmLanguage.json`
   - `lince.sublime-completions`
5. Reinicia Sublime Text

Los archivos `.lince` tendrán resaltado automático.

## Activar manualmente

Si el resaltado no se activa solo:
1. Abre un archivo `.lince`
2. Ve a **View → Syntax → Lince**

## Lo que incluye

- ✅ Resaltado completo de sintaxis
- ✅ Palabras clave en español
- ✅ Cadenas, números y comentarios
- ✅ Clases, funciones y módulos
- ✅ Autocompletado de palabras clave
- ✅ Snippets para constructs comunes

## Snippets (Tab para expandir)

| Prefijo    | Resultado                      |
|------------|--------------------------------|
| `fun`      | función con parámetros         |
| `fun0`     | función sin parámetros         |
| `sea`      | variable mutable               |
| `lista`    | lista tipada                   |
| `dic`      | diccionario tipado             |
| `si`       | condicional si                 |
| `sino`     | si/sino                        |
| `para`     | bucle para clásico             |
| `cada`     | para cada                      |
| `mientras` | bucle mientras                 |
| `hacer`    | hacer...mientras               |
| `clase`    | definición de clase            |
| `clasex`   | clase con herencia             |
| `intentar` | intentar/capturar              |
| `importar` | importar módulo                |
| `esc`      | escribir()                     |
