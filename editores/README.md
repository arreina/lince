# 🐆 Lince — Soporte para editores

Resaltado de sintaxis y autocompletado para Lince en los editores más populares.

## Editores soportados

| Editor        | Resaltado | Snippets | Autocompletado |
|---------------|-----------|----------|----------------|
| VSCode        | ✅        | ✅       | ✅             |
| Sublime Text  | ✅        | ✅       | ✅             |
| Notepad++     | ✅        | ❌       | ❌             |

## Instalación rápida

### VSCode
Copia `vscode/lince-language/` a `~/.vscode/extensions/` y reinicia.

### Sublime Text
Copia `sublime-text/*.tmLanguage.json` y `*.sublime-completions` a una carpeta `Lince` dentro de Packages y reinicia.

### Notepad++
Importa `notepad++/lince-notepad++.xml` desde **Lenguaje → Definir tu propio lenguaje → Importar**.

Consulta el `README.md` dentro de cada carpeta.
