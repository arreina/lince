# 🐆 Lince — Resaltado de sintaxis para Notepad++

## Instalación

1. Abre Notepad++
2. Ve a **Lenguaje → Definir tu propio lenguaje...**
3. Haz clic en **Importar...**
4. Selecciona el archivo `lince-notepad++.xml`
5. Reinicia Notepad++

A partir de ahora, los archivos `.lince` tendrán resaltado de sintaxis automático.

## Lo que incluye

- ✅ Palabras clave de control (`si`, `sino`, `para`, `mientras`...)
- ✅ Palabras clave de declaración (`sea`, `fijo`, `funcion`, `clase`...)
- ✅ Tipos de dato (`numero`, `texto`, `logico`, `lista`...)
- ✅ Literales (`verdadero`, `falso`, `nulo`)
- ✅ Operadores lógicos (`y`, `o`, `no`)
- ✅ Tipos de error (`Error`, `ErrorTipo`, `ErrorRango`...)
- ✅ Módulos estándar (`matematica`, `texto`, `archivos`, `tiempo`)
- ✅ Cadenas de texto
- ✅ Números
- ✅ Comentarios con `#`
- ✅ Plegado de bloques `{}`
